# 跳一跳 (Jump Jump) — 复刻原型

## 原版信息
- **上线时间**: 2017年12月，微信小游戏首发标杆
- **核心玩法**: 按住蓄力 → 松开跳跃 → 落在下一个方块上，居中得高分
- **平台**: 微信小游戏 (Canvas 2D)

## 本原型复刻内容
| 功能 | 状态 | 说明 |
|------|------|------|
| 蓄力跳跃 | ✅ | 按住时长决定跳跃距离/高度 |
| 平台生成 | ✅ | 随机间距与高度 |
| 得分系统 | ✅ | 每跳一个新平台 +1 |
| 连击奖励 | ✅ | 落点居中触发 combo |
| 3D 透视效果 | ❌ | 原版有等距视角，本原型为 2D 简化 |
| 音效 | ❌ | 需 Web Audio API |
| 微信好友排行 | ❌ | 需 WeChat Open Data API |
| 分享复活 | ❌ | 需 `wx.shareAppMessage` |
| 皮肤/角色 | ❌ | 原版有多种棋子皮肤 |

## 运行方式
```bash
# 任意静态服务器
cd prototypes/jump-jump && python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```
或直接双击 `index.html` 打开。

- MVP: HTML5 Canvas + 原生 JS (本原型)
