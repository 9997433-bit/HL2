## 二、逐条人工检查步骤（供 G2 / 验收人参考，不必粘贴）

从仓库根目录 `python3 -m http.server 8000`，Chrome 打开
<http://127.0.0.1:8000/games/fucheng-life/>，先清站点数据并开 Console。

### 37-a 快进三月

1. 开一局新人生进入仪表盘，行动区可见「快进三月 ▸▸」（≤640px 视口在「更多」抽屉内，
   按钮文案「快进三月」）。
2. 点击后出现确认弹窗（「快进会自动花完行动点并连续推进 3 个月。遇到大事会停下。确定？」），
   确认后自动按「本月建议」优先级花完 AP 并连续推进，正常情况下月份 +3。
3. 中断路径逐一验证：
   - **AP 花不完**：清掉探区目标使某行动不可用时，日志出现
     「快进中止：行动点花不完（可能缺探区目标）」，快进停在当月；
   - **强弹窗**：快进途中弹出合约结算 / 危机 / O1 时，弹窗正常可交互，
     处理后日志出现「快进被一件事打断」，不继续推进剩余月份；
   - **结局**：推进中触发终局则停在终局弹窗，不再快进。
4. 快进结束后 HUD 数值与日志逐月流水一致；重复点击快进不会并发叠跑
   （`fastForwarding` 守卫，进行中再点无第二轮）。

### 37-b 闯城目标 ↔ 合约绑定

1. 出身页选「闯城 60 月」开局，主目标选「落户上岸」→ 签约弹窗里「落户」卡排第一，
   卡上有「匹配主目标」角标，导语含「你的闯城主目标是「落户上岸」」句式提示。
2. 重开分别验证：「攒够首付」→「首付」置顶带角标；「向上爬一层」→「升职」置顶带角标；
   「还清负债」→ 无角标、三卡保持 pack 原顺序、导语无推荐句。
3. 推荐置顶时按数字键 `1`，签到的是推荐卡本身（排序落在数组而非仅 DOM）。
4. 完整人生档（非闯城）无主目标，签约弹窗一切照旧、无角标。
5. Console 快验：`FC.Sim.contractForGoal("downpay") === "home"`、
   `FC.contract.recommendedId({ goal: { id: "rise" } }) === "promote"`、
   `FC.Sim.contractForGoal("debtfree") === null`。

### 37-c 每月最多 1 个强弹窗

1. 优先级 `合约结算 > 合约要约 > 危机 / O1`（`monthModal`）：把合约推到到期月，
   该月只弹合约结算卡，同月不再叠危机或随机 O1。
2. 危机命中的月份不再出随机 O1（`sinceModal` 归零）；账单抽屉、inline 日志、
   探区回执不算强弹窗，不占当月名额。
3. 连续推进 6 个月记录每月 modal 数，任一月不超过 1。

### 37-d 危机去重

1. 连续推进直至触发两次「本月危机」，两次危机 id 不同（标题/文案不重复）。
2. Console 快验：多次
   `FC.Sim.pickMonthCrisis(run, era, origin)`（满足间隔条件时）返回的 `id`
   不在 `run.recentCrisis` 尾窗内复读；`run.recentCrisis.length <= 4`。
3. 老存档（无 `recentCrisis` 字段）载入不报错，字段被补为 `[]`。

### 37-e 自动化门禁

```bash
./scripts/run-fucheng-life-tests.sh
```

退出码 `0`，全部 suite 通过，其中应包含 R14 断言
（`games/fucheng-life/tests/r14-flow-fixes.test.js`：快进符号、弹窗帽、合约推荐、危机去重）。
