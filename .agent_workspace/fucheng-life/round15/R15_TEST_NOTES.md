# R15 测试入口与预期

## 自动化入口

从仓库根目录执行：

```bash
node games/fucheng-life/tests/r15-ff-guards.test.js
./scripts/run-fucheng-life-tests.sh
```

预期：R15 专项断言通过；全量测试汇总为 `0 failed`，命令退出码均为 `0`。

## 手工入口

从仓库根目录启动静态服务：

```bash
python3 -m http.server 8000
```

使用最新版桌面 Chrome 打开
<http://127.0.0.1:8000/games/fucheng-life/>，清除站点数据并打开 DevTools Console。
移动端回归使用设备模式，视口宽度设为 `390px`。

## 场景与预期

1. **快进不代做探区**
   - 先设一个探区目标，再点击「快进三月」并确认；另开一局不设探区目标重复操作。
   - 预期：确认文案明确说明不会自动探区；自动花 AP 时跳过「探区」，两种情况下均不擅自执行探区，也不清除或改写既有探区目标。

2. **低现金行动护栏**
   - 将现金降到低位并保留可用 AP，触发快进自动行动。
   - 预期：有合法工作行动时优先「工作」，不先执行会继续消耗现金的学习或休息；行动、现金和日志只结算一次。

3. **快进打断进度文案**
   - 分别在第 1、2、3 个月制造强弹窗或终局打断。
   - 预期：提示准确写出「快进走了 k/3 月」；第 1、2 月中断说明剩余月份未走，第 3 月完成后不再显示「剩下的没走」。

4. **合约结算补弹与幂等**
   - 将合约推进到成功和失败状态，先不确认结算就刷新或重新进入仪表盘。
   - 预期：未领取的结算重新弹出；确认结算选项后才应用对应奖励或惩罚并标记已领取。
   - 再次刷新或进入仪表盘时不补弹，现金、属性、日志及其他奖惩均不重复入账；老存档缺少领取标记时可安全迁移。

5. **危机概率闸**
   - 在满足危机冷却的状态下连续推进多组月份；确定性边界以 R15 自动化用例为准。
   - 预期：危机不会在每个满足冷却的月份必然触发；命中后仍遵守近期危机去重，并继续受每月最多一个强弹窗的限制。

6. **回归**
   - 桌面与 `390px` 各走一次「开局 → 设探区目标 → 快进 → 处理合约结算/危机 → 返回仪表盘」。
   - 预期：探区目标保留，主按钮和补弹可操作，弹窗无叠层，页面无横向溢出，Console 无 error、未处理 Promise rejection 或 404。
