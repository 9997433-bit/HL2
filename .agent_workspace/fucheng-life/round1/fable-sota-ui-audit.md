## 0. Executive Summary

- **文字人生模拟品类（BitLife、人生重开模拟器）在视觉上普遍是"反华丽"的**：裸 HTML、系统字体、零动效。它们贡献的是**仪式结构**（十连抽天赋、逐年点击、人生总结、稀有度色阶），不是视觉语言。《浮城人生》的机会 = 保留这套已验证的仪式骨架，替换掉它们从未做过的视觉皮肤。
- **视觉语言的 SOTA 在品类之外**：都市夜景氛围与图形设计密度看绝区零（ZZZ）的「post-design」路线（招牌/广告牌图形设计撑起城市沉浸，静态高完成度包装 + 少量刻意的动效转场）；信息层 HUD 语言看 Cyberpunk 2077（角标括线、扫描线、故障字形、诊断式排版）；决策仪式与后果预览看 Reigns（卡牌物理 + 资源增减预告）。
- **「华丽」不等于堆特效**。审计结论：华丽感 70% 来自三件便宜的事——①分层纵深（背景视差天际线 / 中景玻璃拟态面板 / 前景光效粒子），②光的语义化（霓虹色只给可交互物和状态变化，其余压暗），③微动效的节拍（数字滚动、卡片入场 stagger、按压反馈 ≤200ms）。剩下 30% 才是雨、粒子、故障效果等氛围件。
- 针对《浮城人生》五个 Round 1 界面（入城登记 / 出身选择 / 人生仪表盘 / 城市地图 / 事件弹窗），本文给出 **24 个可挪用参考模式**（§4）与 **P0/P1/P2 三级必做特效清单**（§5），全部标注 CSS/JS 实现要点与性能红线（transform/opacity 合成层动画、单 canvas 粒子层、`prefers-reduced-motion` 降级）。
- 加权评分（§3）：ZZZ 主菜单 4.5/5 为总分最高的华丽参照，Cyberpunk HUD 4.1，Reigns 3.0，人生重开 1.2，BitLife 1.0——分数低的两个恰恰是**信息架构**得分最高的，印证"骨架取国产文字人生模拟、皮肤取都市霓虹 SOTA"的合成策略。

## 1. 「华丽」评分维度（为《浮城人生》定制的 Rubric）

「华丽」在本项目语境 =《浮城人生》PROGRESS.md 要求的「霓虹渐变、玻璃拟态、粒子/光晕、精致 typography」+ 剧情摘要的「霓虹沉默、雨夜反光、城中村灯牌、CBD 玻璃幕墙」。拆成六个可打分维度：

| # | 维度 | 定义 | 权重（浮城人生） |
|---|------|------|------|
| D1 | **霓虹都市夜色** Neon Urban Night | 夜景基调、霓虹渐变/发光、城市剪影、招牌感图形设计 | ×1.5（题材核心） |
| D2 | **分层纵深** Layered Depth | 背/中/前景分离、视差、玻璃拟态、elevation 阴影体系、Z 轴叙事 | ×1.5（五层城市的视觉隐喻） |
| D3 | **微动效** Micro-animations | 按压/悬停反馈、数字滚动、入场 stagger、转场编排、动效节拍感 | ×1.5（题目点名） |
| D4 | **Typography & 图形密度** | 字重对比、中文排印质量、编号/标签/条码等"城市信息噪声"图形件 | ×1.0 |
| D5 | **信息编排** Information Choreography | 高密度数据的可读性、状态变化的可感知性、注意力引导 | ×1.0 |
| D6 | **氛围件** Atmosphere FX | 雨、雾、粒子、光斑、扫描线、噪点等环境效果 | ×0.5（锦上添花） |

评分 0–5：0=无 / 1=雏形 / 3=行业平均 / 5=同类最佳。加权满分 35。

## 2. 五类参照逐项审计

### 2.1 BitLife（Candywriter）— 品类信息架构的原型

**界面构成**：顶部年龄+姓名栏 → 中间逐年文字时间线（日志流）→ 四条核心属性条（Happiness/Health/Smarts/Looks，红绿渐变色块）→ 底部五格 Tab（Occupation/Assets/Age+/Activities/Relationships），中央 "Age" 按钮是唯一主动作。

**做得好（可取）**
- **单一主动作仪式**：巨大的 "+ Age" 居中按钮，一次点击 = 一年人生，日志逐条追加。节拍极清晰，这就是人生模拟的核心循环 UI 化。
- **属性条语义色**：数值高低直接映射红→黄→绿，扫一眼即知人生状态；条内数字+emoji 双编码。
- **日志的口语化短句**：每条事件一行、首行 emoji 分类，可扫读。与《浮城人生》「短句有力」的文案风格天然兼容。
- **Tab 分区稳定**：职业/资产/关系/活动四大系统各占一格，与我们的 金钱/技能/关系/风险 四系统可一一对应。

**做得差（引以为戒）**
- 视觉零氛围：纯白底、系统 UI 字体、iOS 原生控件感，D1/D2/D6 全部为 0。
- 属性条动画生硬（瞬跳），数值变化缺少"发生了什么"的戏剧感。
- 弹窗是系统 Alert 样式，重大人生事件（结婚/入狱/死亡）与买杯咖啡的视觉重量相同。

**对浮城人生的移植**：保留"逐年推进 + 日志流 + 属性条"三件套作为仪表盘骨架；把 Age 按钮改造成霓虹主按钮（见 §4-P13）；重大事件必须升格为全屏叙事弹窗（§4-P20）。

### 2.2 Reigns（Nerial）— 决策仪式与后果预览的教科书

**界面构成**：顶部四个资源图标（教会/民众/军队/国库，图标内液面高度=数值）→ 中央一张人物卡牌 + 一句台词 → 左右滑动二选一 → 底部年份计数。

**做得好（可取）**
- **卡牌物理**：拖拽时卡牌跟手倾斜（rotate 随 drag distance），越过阈值出现选项文案，松手飞出+下一张滑入。整套交互 100% 可用 CSS transform + pointer events 复刻。
- **后果预览点**：拖到一侧时，将受影响的资源图标上方浮现小圆点（不透露增减方向，只透露"会动"）。制造决策张力的最小 UI，成本极低。
- **资源液面**：图标内部液体升降代替数字，变化时液面波动一下。抽象但可感知。
- **死亡/换代转场**：全屏定格 + 讽刺墓志铭 + 年代计数，把"一世结束"做成仪式。与我们「入城登记 E1-E7 换代」的概念同构。
- 极简双色调让**唯一的动效获得全部注意力**——华丽不是元素多，是注意力编排。

**做得差**
- 平面插画风与霓虹都市气质不合，D1=0；长局重复感强，卡面视觉不随剧情推进升级。

**对浮城人生的移植**：事件弹窗采用"滑动抉择卡"交互（§4-P19）；资源预览点用于金钱/关系/风险图标（§4-P21）；换代/死亡全屏仪式化转场（§4-P22）。

### 2.3 人生重开模拟器系（lifeRestart / 中国式家长 / 众生游）— 中式人生模拟的仪式库

**人生重开模拟器（2021 现象级网页游戏，开源）界面流**：
`天赋十连抽（146 种天赋，稀有度 黑/蓝/紫/橙 四阶）→ 三选天赋 → 20 点分配到 颜值/智力/体质/家境（可一键随机）→ 逐年点击出事件 → 死亡 → 人生总结（七项数值+分级评语变色）→ 天赋继承进入下一世`。

**做得好（可取）**
- **开局即抽卡**：把 gacha 的稀有度多巴胺嫁接到人生开局，"十连抽天赋"是被验证过病毒式传播的仪式。《浮城人生》的出身选择（寒门/中产/体制内/富商…）+ 时代选择（E1-E7）可直接套用"抽/选混合"开局。
- **稀有度色阶**（黑→蓝→紫→橙）：一套全社区通识的颜色语义，玩家零学习成本。可映射到浮城的出身卡与事件级别。
- **属性四轴 + 点数预算**：分配即叙事（"把家境点满还是智力点满"本身就是价值观表态），与 UI 摘要中「出身档案」完全对齐。
- **人生总结的分级评语**（"颜值：0 地狱"）：数值→评语→颜色三联动，廉价但记忆点极强；配合浮城冷峻文案风（「没钱的人没有秘密」）会非常出彩。
- **继承机制入口**：下一世保留一个天赋——UI 上就是"选一张卡带走"，天然的 run 间钩子。

**做得差（正是我们的机会）**
- 视觉是刻意的裸 HTML（`<ul>` + 默认按钮），D1-D6 几乎全 0。它证明了**这套仪式骨架不靠视觉也能爆**——给它穿上霓虹皮肤是纯增量。
- 逐年事件是瞬间追加，没有 typewriter/入场动画，长日志无节奏。

**邻近参照**
- **中国式家长**：属性面板用"挖脑洞"格子消除包装数值成长——启示：数值获取可以游戏化包装，但 Round 1 不做小游戏，只取其"属性成长要有仪式"。
- **众生游**：写实向 UGC 人生模拟，事件卡配实景插图+暗色 UI，证明中式写实题材配深色氛围 UI 成立。

**对浮城人生的移植**：开局流程 = 时代选择（E1-E7 横向时间轴）→ 出身抽/选（稀有度发光卡）→ 属性分配（霓虹刻度条），完整继承 lifeRestart 仪式并全面视觉升维（§4-P10~P12）。

### 2.4 Cyberpunk HUD 语言（Cyberpunk 2077 及同类）— 信息层的视觉语法

审计对象：Cyberpunk 2077 游戏内 HUD/菜单、同系散布于 FUI（Fictional UI）社区的赛博 HUD 惯用法。

**核心语法（可取，全部低成本 Web 可实现）**
- **角标括线框（corner brackets）**：面板不画完整边框，只画四角 L 形短线 + 细描边，科技感来自"未闭合"。CSS：伪元素 + `border` 两边。
- **诊断式排版**：面板角落缀小号等宽字标签（`SYS.L2 // 工薪层`、`ID:E5-0347`）、条码、十六进制杂讯。信息噪声=世界观质感。对应浮城「城市照常运转，你只是节点之一」的主题。
- **扫描线与噪点**：全屏 2-4% 透明度的 repeating-linear-gradient 扫描线 + SVG feTurbulence 噪点，瞬间去"网页感"。
- **Glitch 字形**：标题在 hover/切换时 2-3 帧的 RGB 通道错位（clip-path 切片 + translate + 双色 text-shadow）。用于换层/风险事件，不常驻。
- **色彩语义**：主青（信息）/警黄（提示）/危红（红线）三色制，配合浮城 L5「暗流·深红紫黑」天然成立。
- **数据即装饰**：折线、雷达图、进度环本身当装饰元素用——仪表盘的属性可视化可以同时是画面主体。

**引以为戒**
- 满屏发光=没有发光；2077 本体也因 HUD 信息过载被批评。**发光预算制**：同屏持续发光元素 ≤3 处。
- 长时间扫描线/抖动伤可读性与舒适度，必须弱、慢、可关（`prefers-reduced-motion`）。
- 浮城是**现实主义**都市，不是义体朋克——取其 HUD 语法（括线/标签/扫描线），弃其科幻符号（电路纹、机械齿轮），情绪基调用「冷静诗意」而非"高能战斗"。

### 2.5 抽卡手游主菜单（ZZZ / 崩铁 / 原神 / 明日方舟）— 华丽包装的工业标准

**绝区零 ZZZ（最相关参照，官方创作笔记佐证）**
- **「post-design」都市美学**：官方明确"好的都市题材重度依赖大量招牌与广告图形设计"——用建筑与品牌平面设计制造沉浸，正是浮城「城中村灯牌 / CBD 玻璃幕墙」要走的路。启示：**把 UI 元素做成城市招牌**（霓虹灯管字、灯箱面板、地铁导视牌式按钮）。
- **静态高完成度 + 少量刻意动效**：官方自述资源有限时选择"高质量视觉包装 + 极少但精准的动效转场"。这就是我们 Web 端的正确策略——不追全屏 Live2D，追**每个动效都打在节拍上**。
- **左松右密构图**：角色开发界面右侧信息极密时，左侧留白+角色展示放松，整体平衡。仪表盘可照搬：左侧人物档案区留白，右侧数据密排。
- **Kinetic typography 转场**：大号字块斜切飞入、色块 wipe、比例夸张的标题字——CSS clip-path + transform 可 80% 复刻。
- **菜单即街区**：Sixth Street 把主菜单做成可漫游街道。Web MVP 不可行，但降维版可行：**主菜单 = 一幅可视差滚动的城市剖面**，五层 L1-L5 就是"街区即菜单"。

**崩坏：星穹铁道**：玻璃拟态面板 + 星轨线条 + 柔和光晕的典范；菜单层级切换用"缩放+模糊背景"制造 Z 轴纵深——`backdrop-filter: blur()` 直接对应。
**原神**：克制的半透明白 + 金色描边，信息大屏清爽；启示是**留白也是华丽的一部分**，但其素雅基调与浮城夜色不合，只取其层级清晰。
**明日方舟**：工业风平面构成——斜切分割、大面积几何色块、超大编号字（RHODES ISLAND 式）、低饱和+单点高亮。与"冷静现实主义"气质最合拍，是浮城 typography 的首选参照：**大号斜体数字编号（年龄/年代/楼层）+ 小号注音标签**。

**共同的工业标准（必须达到才算"手游级华丽"）**
1. 任何可点元素都有 ≤150ms 的按压反馈（缩放 0.97 + 高光）。
2. 界面切换永远有方向性转场（wipe/slide/fade+scale），绝无生硬跳变。
3. 数值变化必滚动（count-up），资源图标 + 数字飞入托盘。
4. 列表/卡组入场必 stagger（每项延迟 30-60ms）。
5. 至少一层环境动效常驻（粒子/光斑/呼吸光），让静止画面也是"活的"。

## 4. 参考模式库（24 个，映射到 Round 1 五界面）

### A. 全局基底（所有界面共用）

| # | 模式 | 来源 | 落地要点（HTML5/CSS/JS） |
|---|------|------|------|
| P1 | 三层纵深舞台 | ZZZ/崩铁 | 背景层（城市剖面 SVG/渐变天际线，视差 `translateY` 随滚动/鼠标 ±10px）→ 内容层（玻璃拟态面板）→ 效果层（单个全屏 `<canvas>` 粒子+光斑）。三层用 `position:fixed` + `z-index` 固定次序 |
| P2 | 玻璃拟态面板体系 | 崩铁 | `background: rgba(13,18,30,.55); backdrop-filter: blur(16px) saturate(1.2); border:1px solid rgba(255,255,255,.08)`；elevation 用阴影+描边亮度分 3 档 |
| P3 | 角标括线框 | Cyberpunk | 面板四角伪元素 L 线（`border-top+border-left` 8×8px），hover 时角标外扩 2px |
| P4 | 霓虹渐变主色系统 | ZZZ/2077 | CSS 变量五层色：`--l1:#ffb347`(暖黄) `--l2:#6b8cae`(蓝灰) `--l3:#3ddc97`(青绿) `--l4:#d4a437→#9b59d0`(金紫) `--l5:#8b1e3f`(深红紫黑)，直接取自 STORY_EXTRACT 分区色 |
| P5 | 扫描线+噪点罩层 | Cyberpunk | 全屏 `repeating-linear-gradient` 2px 扫描线（opacity .03）+ SVG feTurbulence 噪点（opacity .04），`pointer-events:none`，`prefers-reduced-motion` 时静止 |

## 5. 必做特效清单（Must-have Effects）

性能红线（全清单适用）：只动画 `transform`/`opacity`/`filter`；粒子统一进一个 `<canvas>`（≤120 粒子，`requestAnimationFrame`，页面隐藏时暂停）；`backdrop-filter` 面板同屏 ≤4 块；全局尊重 `prefers-reduced-motion`（降级为静态+瞬时切换）；目标 60fps 中端手机。

### P0 — 没有它们就不"华丽"（Round 1 验收线）

| 特效 | 应用处 | 实现 |
|------|------|------|
| 霓虹发光文字/描边（三层 text-shadow + 呼吸） | 标题、主 CTA、当前层级名 | 纯 CSS，`@keyframes` 3-4s 呼吸 |
| 玻璃拟态面板 + elevation 阴影三档 | 所有面板 | `backdrop-filter: blur+saturate`，见 P2 |
| 城市剖面/天际线多层视差 | 主菜单、地图背景 | 2-3 层 SVG/PNG 剪影，鼠标/陀螺仪 `translate` |
| 数字滚动 count-up | 金钱、属性、年龄 | rAF 插值 + `toLocaleString`，400-800ms ease-out |
| 卡片/列表入场 stagger | 出身卡、日志、地图层 | `animation-delay: calc(var(--i)*60ms)` |
| 按压/悬停微反馈 | 一切可点元素 | `:active{transform:scale(.97)}` + hover 高光 ≤150ms |

## 6. 反模式清单（审计中确认要避开的坑）

1. **满屏常亮霓虹**——违反「霓虹沉默」基调；执行 P7 发光预算制，暗底才衬得起光。
2. **科幻符号错配**——电路板纹理/机甲角框会把现实主义都市拽成太空歌剧；HUD 语法只取括线/标签/扫描线。
3. **动效无节拍**——所有元素同时动=没有主角；每次转场只允许一个主角动效+若干跟随。
4. **长日志无锚点**——人生重开的教训；用年份大号编号与稀有度左描边给日志流建立扫读节奏。
5. **重大事件轻量化**——BitLife 的教训；死亡/破产/触红线必须全屏仪式化。
6. **爽文腔弹窗**——金色爆闪+"恭喜发财"违背文案基调；结算也要冷静（「账单已扣款。这个月你还剩 ¥1,204。」）。
7. **忽略降级**——扫描线/粒子/blur 必须探测 `prefers-reduced-motion` 与低端设备（`navigator.hardwareConcurrency`）后降档，否则华丽变卡顿。
