# 《浮城人生》Round 3 手工验收

本清单是发布门禁，不是功能愿望单。请从仓库根目录执行：

```bash
python3 -m http.server 8000
```

使用最新版桌面 Chrome 打开
<http://127.0.0.1:8000/games/fucheng-life/>。先清除站点数据并打开 DevTools Console；
涉及移动端的项目使用 DevTools 设备模式，视口设为 `390px` 宽。每项通过后勾选并在末尾记录环境。

## 15 项门禁

1. [ ] **P0-1 · 霓虹标题与主 CTA 可见**  
   主入口、年代、出身、仪表盘和地图均有清晰页面标题；主操作按钮无需滚动猜测即可识别，文字与背景对比正常。

2. [ ] **P0-2 · 玻璃拟态三档 elevation**  
   检查基础卡片、悬浮/操作面板、事件或账单 overlay：三档背景深度、模糊、描边和阴影层级可区分；
   关闭浏览器 `backdrop-filter` 后内容仍清晰可读。

3. [ ] **P0-3 · 入口视差与核心屏氛围动效**  
   主入口移动指针时三层天际线有平滑视差；至少一个核心屏可见呼吸光、雨、粒子或窗灯等氛围动效，
   且不遮挡点击。

4. [ ] **P0-4 · 仪表盘 count-up**  
   初次进入仪表盘及推进月份后，现金、健康、人脉、声望、年龄、负债数字从当前显示值平滑滚到新值；
   最终数值与日志/结算一致。

5. [ ] **P0-5 · 卡片 stagger 与日志增量动画**  
   年代/出身卡片按顺序入场。推进月份后只有新增日志项播放入场，已有日志不重新闪烁或整列重播。

6. [ ] **P0-6 · 全局按压反馈**  
   主按钮、卡片按钮、地图地点、事件选项和账单确认按钮在鼠标按下/触摸时都有约
   `scale(.97)` 的即时反馈，松开后恢复，不导致布局跳动。

7. [ ] **P0-7 · 屏间 wipe 转场**  
   按「主入口 → 年代 → 出身 → 仪表盘 → 地图」前进及返回时有方向正确的 wipe；
   快速点击不会卡在遮罩层，浏览器后退后页面仍可操作。

8. [ ] **P0-8 · 五层色贯穿 HUD/地图/事件**  
   L1 市井、L2 工薪、L3 上升、L4 资本、L5 暗流各自颜色可区分；当前圈层色在仪表盘 chip/电梯、
   地图层级和对应事件边框或场景标签中一致。

9. [ ] **O1 · 三个月内至少一次事件弹窗**  
   从新人生连续点击「推进一个月」最多 3 次，应出现至少一次城市事件。选择任一选项后能看到后果预览、
   结果入账，并可「记入日志，继续」；关闭后焦点与滚动恢复。

10. [ ] **叙事单一数据源**  
    年代和出身页展示分别为 7/10 条，内容与 `data/story.json` 一致；检查 Network 只加载该 JSON，
    `screens.js`/各 HTML 中不存在另一套年代或出身文案数组。

11. [ ] **O2 · 账单抽屉或等效 tick 结算仪式**  
    推进月份后出现月度结算：房租、通勤、伙食、人情、杂费、还贷、收入与净流清晰列出并逐行入账。
    「结清，继续」、Escape 和遮罩关闭均可用，焦点受控，HUD 最终金额与净流一致。

12. [ ] **390px 无横向溢出**  
    在 `390px` 宽逐页走完整流程；页面、事件弹窗、账单抽屉、地图和操作栏均无横向滚动条，
    无裁字、叠字或屏外主按钮。

13. [ ] **Chrome happy path 零 console error**  
    清空 Console 后完成「入口 → 年代 → 出身 → 推进 3 月并处理事件/账单 → 地图 → 返回仪表盘」；
    全程没有 error、未处理 Promise rejection、404 或失效资源。

14. [ ] **`prefers-reduced-motion` 降级可用**  
    DevTools Rendering 设为 `prefers-reduced-motion: reduce` 后刷新并重走流程。视差、呼吸、闪烁、
    stagger、wipe 和数字滚动可静态/即时完成；事件冷静期、导航、结算和焦点操作仍可用。

15. [ ] **自动化门禁全绿**  
    在仓库根目录运行以下命令，退出码为 `0`，所有 suite 均报告通过：

    ```bash
    ./scripts/run-fucheng-life-tests.sh
    ```

## O1 事件库与出身 Mini-Saga 验收（R1 门禁，详见 `.agent_workspace/fucheng-o1-origin-sagas/round1/fable-sota-gates.md`）

21. [x] **O1 · 50+ 事件单一数据源**  
    Network 面板确认事件与 choices 只来自 `data/story.json`（≥ 50 条）；随机触发 3 个事件，
    每个都有 2–3 个选项且可完整走完「选择 → 结果 → 记入日志」；老存档载入不报错。

22. [x] **O1 · 层级色与红线冷静期**  
    分别触发 L1–L5 各一个事件，弹窗强调色与该层 cityLayers 色一致；触发一个「风险」事件：
    3 秒倒数期间选项禁用、ESC 与遮罩点击无效；`prefers-reduced-motion: reduce` 下冷静期仍保留。

23. [x] **O1 · 金钱单位换算一致**  
    选择一个含金钱变化的选项，结果面显示的 ¥ 与 HUD 现金变化完全一致；
    低收入档（月入 ≤ ¥1300）验证每单位不低于 ¥400 的下限生效。

24. [x] **Saga · 出身链触发与完成**  
    任选一个出身开新局：入城后 3–18 月窗口内出身链第一步出现（推进至第 18 月仍未出现即失败）；
    全链 3–4 步、至少一步有选项；走完后日志留痕，同一局不再复发；换另一出身开局，不会串到别人的链。

25. [x] **内容质量抽检**  
    随机抽 10 条事件 + 2 条出身链人工评审：无占位符/系统腔/中英混杂残留，
    文案写实且选项因果自洽，无逐字重复；`d.money` 均为 ±5 以内的单位值而非绝对金额。
